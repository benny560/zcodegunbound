# 老计算器 (Trico 3in1) 公式还原与核对结论

## 已还原的公式结构(从2.2.3反编译追踪数据流得出)

### 1. 角度求解(核心)
老计算器用 **atan 求角度,乘 57.29(=180/π)转度数**:
```
角度 = atan(...) × 57.29
```
**与现计算器一致**:`Math.atan(tanA) * 180 / Math.PI`(57.2958)。

### 2. 速度↔力度转换
老计算器的 `768.245`、`716.53` 是**初速度**(像素/秒),通过 `× PF` 转力度:
```
768.245 × 0.004332712 = 3.3286  → 力度 ≈ 3.33
716.53  × 0.004332712 = 3.1045  → 力度 ≈ 3.10
```
**与现计算器完全一致**:`velocity = power / PF`(`power = velocity × 0.004332712`)。
**这证实老计算器和现计算器用的是同一个 PF(0.004332712)和同一套速度-力度体系。**

### 3. 距离修正(分段线性)
成对系数 `1.8667 / 0.04667` 和 `1.7 / 0.03` 是分段线性修正:
```
0.04667 × 40 = 1.8667   (40 = DISTANCE_PIXELS_PER_20SD)
1.8667 / 40  = 0.04667
```
即:**系数 = 单位距离增量 × 距离**。这是 `y = k·distance + b` 形式的分段插值。
- 段A:`k=0.04667/SD`(或 `1.8667` 是某距离的累计值)
- 段B:`k=0.03/SD`

现计算器用的是 `empiricalPhaseTables`(识别表)+`rederivedPhasePhysicsN123`(多项式),结构不同但目的一致(都是把距离→角度/力度)。**老版用简单2段线性,现版用更精细的多项式/查表**。

### 4. 风力修正(3档固定)
```
0.95, 0.94, 0.9  (风力衰减3档)
```
递减的3个系数,对应不同风力强度区间的衰减因子。
现计算器用 `WIND_CORRECTIONS` 自学习系统(动态加权平均),**比老版固定3档更先进**。

### 5. 相位/圈数
```
10.2824 × 57.29 = 589.08  (度)
5.6566  × 57.29 = 324.07  (度)
0.105, 4.02, 0.005, 0.025  (相位小修正)
```
10.2824、5.6566 是旋转圈数/相位换算系数(与现计算器的 `OMEGA_K=0.03073`、`phaseFormulas` 多项式对应,具体数值体系不同)。

### 6. 重力(双模型确认)
```
g = 196 (GME物理)   ← 现计算器全局 Gravity
g = 430 (Excel物理)  ← 现计算器 TRICO.gravity
g = 9.8 (原始)       ← 196 = 9.8×20
```
**老计算器同时实现了两套模型,与现计算器架构完全对应。**

## 核对结论总表

| 项目 | 老计算器(2.2.3) | 现计算器 | 一致性 |
|------|----------------|---------|--------|
| PF(力度系数) | 0.004332712(由768→3.33反推) | 0.004332712 | ✅ **完全一致** |
| 速度↔力度转换 | velocity × PF = power | velocity = power/PF | ✅ **完全一致** |
| 角度求解 | atan × 57.29 | atan × 180/π | ✅ **一致**(57.29≈180/π) |
| 重力(Trico) | 430 | 430 | ✅ **一致** |
| 重力(GME) | 196 | 196 | ✅ **一致** |
| 距离修正 | 2段线性(1.8667/1.7) | 多项式+查表 | ⚙️ **结构不同,现版更精细** |
| 风力修正 | 固定3档(0.95/0.94/0.9) | 自学习加权平均 | ⚙️ **现版更先进** |
| 相位/圈数 | 10.2824/5.6566 固定系数 | OMEGA幂律+多项式 | ⚙️ **现版不同体系** |

## 最终判断

**老计算器与现计算器在物理基础上是完全一致的**(同一个 PF、同一套速度-力度转换、同样的 atan 求角度、同样的双重力模型 g=196/430)。

**差异在于"修正精度"**:老版用简单的分段线性+固定风力档位,现版用更精细的多项式拟合+查表+自学习风力修正。这意味着:
- **基础弹道公式可信**(两版同源)
- **现计算器在风/距离/相位的修正上比老版更精确**,不是"少了什么",而是"更精细了"
- 老版的固定系数(1.8667/10.2824/0.95等)可作为**基准参考值**验证现计算器的输出是否在合理范围

## 可用于核对的基准值
若现计算器输出偏离以下老版基准,说明可能有bug:
- 标准力度区间:3.10~3.33(对应速度 716~768)
- 角度转度系数:57.29
- 距离修正斜率:0.04667/SD 或 0.03/SD
- 风力衰减:0.9~0.95
