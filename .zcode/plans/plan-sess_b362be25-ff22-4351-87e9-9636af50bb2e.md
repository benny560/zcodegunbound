# 方向B：旋转相位守恒求解器

## 核心改动

在 `EXCEL_TRICO` 里新增一个求解器 `calcPhaseConstraintSolver`，用旋转约束 `ω(V)·T = rot_pi(sd)·π` 迭代求解，替代落地时间求解器对 N3/N4 的处理。

## 物理模型

```
约束1 (旋转):  ω(V) · T = rot_pi(sd) · π        ← rot_pi 只依赖 sd，风不改
约束2 (垂直):  tanA = (elev + 0.5·effGrav·T²) / denom
约束3 (速度):  V = denom / (cosA · T)
其中:
  ω(V) = 0.023623·V^0.764315 (右) / 0.687878·V^0.299291 (左)   ← 幂律模型(权威)
  rot_pi(sd) = c0 + c1·sd + c2·sd²                              ← 来自 TRICO_PHASE_FORMULAS.md 表
  denom = xDist − 0.5·xA·T²    (注意: 这里 xDist 是参考距离, 不是强制落点)
  effGrav = G − sinW·force/MASS
```

## 迭代算法（TRICO_PHASE_FORMULAS.md 2.4 节，已验证 N2/N3 100%）

```
1. T = T_init  (用现有 T_base+dT 作初值, 加速收敛)
2. tanA = (elev + 0.5·effGrav·T²) / denom
   angle = atan(tanA)
3. V = denom / (cosA · T)
4. ω = 幂律(V)
5. T_new = rot_pi(sd) · π / ω
6. 收敛 |T_new − T| < 1e-4, 否则 T = 0.5·(T + T_new) 重复(阻尼必须, 否则正反馈振荡)
```

## rot/pi(sd) 多项式系数（来自 TRICO_PHASE_FORMULAS.md 表，无风识别表拟合）

## 关键风险与对策

1. **rot/pi 多项式是无风拟合的，有风时是否准？** 你确认"风改T但rot/pi不变"。先用 4 标准点验证这个假设成立。
2. **迭代收敛性**：阻尼 0.5 是文档验证过的。初值用 T_base+dT 应该 3-5 次收敛。
3. **背射/N1 不切换**：保持现有路径，降低风险。
4. **denom 的角色变了**：现有方法用 denom=0 当"无解"硬约束（落点必须=目标）。方向B 里 denom 只是参考距离的中间量，球可以飞过目标（旋转命中）。但 denom≤0 仍可能让 V 算出负值，保留 null 兜底。
