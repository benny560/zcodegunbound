## 任务 2：角化力诊断报告（不改代码）

### 已确认的事实（直接回答用户疑问）

**角化力（取整解↓/↑）是有风值，不是无风值。**

调用链追踪：
1. `calcTimePhysicsSolver`（行 3413，有风主路径）返回 `centerResult`，其中：
   - `effectiveGravity` = `effGravCalc = G_base - sinW·force/MASS`（**含风**，行 3454）
   - `xA = cosW·force/MASS`（**含风**，行 3429）
   - `time` = `T_target = T_base + dT`（**有风时间**，dT 含 wy_acc）
2. `calcTricoRoundedPower`（行 9624，取整算法唯一信源）读取 `sol.centerResult` 的这三个量：
   - `effGrav = parseFloat(cr.effectiveGravity)`（有风）
   - `xA = parseFloat(cr.xA)`（有风）
   - `T_raw = parseFloat(cr.time)`（有风时间）
3. 落点守恒法（优先）：`denom = effGrav + xA·tanT`，`T² = 2·(tanT·xTarget − yTarget)/denom`
4. T守恒法（回退）：`V_tc = (yTarget + 0.5·effGrav·T²)/(sinT·T)`，代入 yTarget 后 **effGrav 精确抵消** → `V_tc = rawV·sinRaw/sinT`（仅与角度正弦比有关）

**学习推荐的角化力**同样基于有风 sol（行 8347 `_learnRoundRow` 调 calcTricoRoundedPower）。

### 待诊断的核心疑点（报告将实测验证）

用户"逆风时角化力偏小"的可能根因，报告会逐一排查：

**疑点 A：force 在 wa≈180° 的离散跳变**
- 行 3428：`force = |cosW+1|<0.001 ? ws : max(0, ws-1)`
- wa=180° 时 force=ws；wa=179° 时 force=ws-1 → **力突变 1 个单位** → effGrav/xA 跳变 → 取整解跳变
- 需实测：wa=178/179/180/181 几个角度的取整解对比

**疑点 B：落点守恒法在逆风高角度的系统性偏差**
- 逆风（右射 wa≈180）：xA<0，高角度 tanT>0 → `xA·tanT < 0` → denom 偏小 → T_new 偏大
- 但 V_new = (xTarget − 0.5·xA·T_new²)/(cosT·T_new)，xA<0 使分子增大 → V_new 偏大
- 两效应耦合，需实测确认净方向

**疑点 C：是否误把 powerAtAngleRaw 当"角化力"**
- `powerAtAngleRaw`（行 3482）= raw 力度（未取整），注释明确"角化力取整由出口统一处理"
- 真正的"角化力"是取整解↓/↑（calcTricoRoundedPower 输出）
- 报告会明确两者区别，确认用户看的是哪个值

### 诊断报告产出
- 用无头浏览器（Playwright）实测 3-5 个逆风场景（如 sd=20, wa=170/175/180/185, ws=15/20）
- 抓取：raw角度/力度、取整解↓/↑、effGrav、xA、T、force、dT
- 分析：角化力随 wa 变化曲线，定位跳变点/系统偏差方向
- 给出结论：是"显示口径误解"还是"算法 bug"，若是 bug 给出修复建议（不在本次实施）
